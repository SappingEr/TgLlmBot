## Postgres docker

```bash
docker run -d -e POSTGRES_PASSWORD=postgres -p 5432:5432 postgres:18
```

Connection string

```text
Host=localhost;Port=5432;Database=tgbot;Username=postgres;Password=postgres;
```

## Сворачивание длинных ответов

Ответы LLM сворачиваются в блок «Развернуть ответ», если видимый текст всего ответа
превышает 600 символов или 8 строк. Markdown-разметка в длину не входит; строки считаются
по явным переносам, а не по ширине экрана. Короткие ответы отображаются полностью.

Настройки секции `Telegram` в `appsettings.json` или переменных окружения:

- `Telegram__CollapseLongResponses` — включение сворачивания, по умолчанию `true`.
- `Telegram__ResponseCollapseCharacterThreshold` — порог символов, по умолчанию `600`.
- `Telegram__ResponseCollapseLineThreshold` — порог строк, по умолчанию `8`.

Пороги должны быть положительными. Ответ делится на части с текстом до 4096 символов,
каждая часть сохраняется отдельной записью истории. У длинного ответа все части сворачиваются;
если частей несколько, в заголовке каждого ката отображается номер части.
При выключенном сворачивании части отображаются полностью. Для отправки используется
Telegram Bot API Rich Messages; код, списки, ссылки и таблицы сохраняют форматирование.
При ошибке разметки отправляется упрощённый текст с тем же катом.
